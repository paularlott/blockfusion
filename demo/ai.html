BlockFusion AI demo

Open Assistant and ask “add a row with 3 columns”, then “in row 2 column 1 write a short welcome”. Or select the image, use the image button and Suggest a description. Everything can be undone.

How it works

  • The assistant runs in this browser with small open models: Florence-2-base (MIT) describes images, and Qwen3-0.6B (Apache-2.0) does the quick text actions and the chat, so it downloads once. Nothing leaves the device.
  • The first use of each feature downloads its model (about 275–570 MB), which the browser then caches. The chat needs WebGPU to be quick.
  • The chat sees an outline of the page and can add rows, write into columns and type at the cursor. Small models make mistakes, so each request's changes can be undone from the chat.
  • The page's models, quick actions and chat are all set by the app (see this page's source); the editor offers only what it's given.
  • Columns sit side by side from fusionCSS's medium width (992px) up; on a narrower editing area, with a side panel open on a small screen, say, they stack.

Running it

  • Build the extension (npm --prefix extensions/ai install && npm --prefix extensions/ai run build) and serve this page over http://localhost (npm run demo).
  • To use a server instead, run examples/assistant-server/server.mjs with an OpenAI-compatible model server, and open this page with ?server=http://localhost:8787/assistant.
