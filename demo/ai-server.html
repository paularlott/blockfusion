BlockFusion server AI demo

The same editor with a model on a server (here a local Ollama, through a small relay). Put the cursor in a paragraph and use Assistant actions: the paragraph's HTML goes to the model, so bold, links and coloured text are kept. Open the Assistant chat to change the page, or select the image, use the image button and Suggest a description. Everything can be undone.

How it works

  • The page uses completionsAssistant from the assistant bundle. It builds the prompts, tool calls and image requests itself and sends them in the OpenAI chat completions format, so the backend only relays them: examples/relay.mjs checks a token, adds the model and passes each request to a model server. This demo uses Ollama with inkling-2-mini, one model that rewrites text, chats with tools and looks at images.
  • A quick action sends each paragraph or list item's HTML and gets HTML back. The editor sanitises it before it goes in: only text-level tags, safe attributes and safe link addresses are kept. For a small model, set html: false to send Markdown-style marks instead, as the in-browser demo (ai.html) does.
  • The chat sees an outline of the page and can add rows, write into columns and type at the cursor. Each request's changes can be undone from the chat.
  • The page sends text and images to your backend only; the backend decides which model sees them.

Running it

  • Install Ollama and pull a model that handles text, images and tools: ollama pull inkling-2-mini.
  • Start the relay:
AI_MODEL=inkling-2-mini:latest AI_TOKEN=demo-token node examples/relay.mjs
  • Serve this folder over http://localhost (npm run demo) and open this page. Add ?relay=URL to use a relay elsewhere.
